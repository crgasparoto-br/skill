# Segurança

A política de segurança do catálogo está em [`docs/SECURITY.md`](./docs/SECURITY.md).

Para relatar uma vulnerabilidade sem publicar detalhes exploráveis em uma issue, use um canal privado do proprietário do repositório. Não inclua tokens, credenciais, dados pessoais ou artefatos de auditoria reais em pull requests públicas.
